```bash
pip install numpy matplotlib
python pnlio_symbiotic_sim.py
```

Con `seed=42` (valor por defecto), los resultados son determinísticos y reproducen exactamente los números reportados en el paper — confirmado en `VERIFICACION.md`.

## Resumen

Se modela la co-creación humano-IA como un autómata celular estocástico (grid 100×100) donde la entropía de Shannon actúa como observable colectivo y una memoria estructural persistente (95%) previene el colapso hacia estados triviales. La analogía con el entrelazamiento cuántico-informacional (Cerf & Adami, 1996; Horodecki *et al.*, 2009) es **formal, no ontológica** — se aclara explícitamente en la Sección 6.3 del paper.
